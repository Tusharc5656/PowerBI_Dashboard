## 📋 Project Overview

An enterprise-level interactive analytics dashboard built in **Power BI** that analyzes global disaster data from 2018–2024, processing **5M+ disaster records** with **$250M+ economic loss data** across **190+ countries**. This project demonstrates advanced data visualization, statistical analysis, and business intelligence capabilities aligned with modern data analytics practices.

---

## 🎯 Key Objectives

✅ Surface actionable insights from large-scale disaster datasets  
✅ Enable data-driven decision-making for senior management  
✅ Support country-wise comparison and severity-based analysis  
✅ Identify trends, patterns, and correlations in disaster data  
✅ Create self-serve dashboards for stakeholder accessibility  

---

## 📊 Analytical Approach

### Data Analysis & Insights
- Conducted **quantitative analysis** on **7,000+ yearly disaster occurrences** (2018–2024)
- Identified **temporal trends**, **seasonal patterns**, and **regional correlations**
- Analyzed **disaster category distribution** (each contributing 9–10% of total casualties)
- Discovered **high-impact outliers** and anomalies in casualty and loss data

### Dashboard & Visualization Design
- Developed **6+ interactive Power BI visualizations**:
  - Line charts for trend analysis
  - Bar charts for regional/category comparisons
  - Pie charts for disaster type distribution
  - Scatter plots for correlation analysis
- Created **KPI scorecards** for key metrics monitoring
- Designed **country-wise comparison views** (e.g., economic loss >$10B analysis)

### Advanced Metrics & Data Modeling
- Built **sophisticated calculated metrics**:
  - Total casualties by country and disaster type
  - Economic loss aggregations and rankings
  - Year-over-year growth analysis
  - Casualty rate per disaster occurrence
  
- Established **data models** supporting:
  - Multi-dimensional analysis
  - Drill-down capabilities
  - Dynamic filtering and slicing
  - Cross-filter interactions

### Data Quality & Integrity
- Assessed **dataset structure** and completeness
- Documented **data quality metrics** and validation rules
- Identified and remediated **missing values** and inconsistencies
- Implemented **data validation** checks for analytical reliability
